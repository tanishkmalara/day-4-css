# CSS Learnings

## What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML webpages.

## CSS Syntax

```css
selector {
    property: value;
}
Important CSS Properties
color
background-color
font-size
margin
padding
border
width
height
CSS Selectors

CSS can select elements using:

Element selectors
Class selectors
ID selectors
Hover

The :hover pseudo-class changes the appearance of an element when the mouse is placed over it.

Example:
button:hover {
    background-color: black;
    color: white;
}
